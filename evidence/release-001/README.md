# Release 001 evidence

This directory is generated by `tools/dogfood` from a provider-free,
deterministic Gearbox run. `verification.json` binds the public result, value
receipt, authority policy, and implementation revision. The `runs/` subtree
retains the raw artifacts at the locators named by the compact result.

The receipt contains exact counts and byte measurements plus observed terminal
state. It makes no token, cost, latency, correctness, comparative, or causal
savings claim.
